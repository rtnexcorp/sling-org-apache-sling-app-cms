# New-age CMS – Platform Features

## Goal
Modern platform capabilities that keep Sling CMS **lean** but **production-grade**.

## Feature candidates
### 1. Content quality checks
- Broken links
- Missing alt-text
- Accessibility hints
- Stale content detection

### 2. Modern search
- Unified search across pages/assets
- Saved searches
- Optional semantic search provider (pluggable)

### 3. Audit, history, and rollbacks
- Clear audit log for content changes
- Safe rollback UI

### 4. Environments & promotion
- Draft/stage/prod workflows
- Promote content references safely

### 5. Developer experience
- Config-as-code patterns
- Local dev bootstrap
- Clear plugin registry and extension points
