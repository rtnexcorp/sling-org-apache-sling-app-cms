# AI Audit Service - Testing Guide

## Overview

This guide provides comprehensive testing instructions for the JCR-based AI Audit Service implementation.

## Prerequisites

1. **Sling CMS running** on `http://localhost:8082`
2. **Service user configured**: `sling-cms-ai` with appropriate JCR permissions
3. **AI module deployed**: `mvn clean install -P autoInstallBundle -pl ai`

## Service User Configuration

The audit service requires a service user with permissions to write to `/var/audit/ai`. 

### Create Service User Mapping

Add to `ai/src/main/features/feature.json`:

```json
{
  "service-user-mappings": {
    "org.apache.sling.cms.ai:sling-cms-ai": [
      "sling-cms-ai"
    ]
  }
}
```

### Grant Permissions

Use the Felix Console or create an ACL configuration:

```
/var/audit/ai
  - allow jcr:all for sling-cms-ai
```

### 3. Test via Groovy Console

Navigate to `http://localhost:8082/groovyconsole` and run:

```groovy
import org.apache.sling.cms.ai.audit.*

// Get the audit service
def auditService = getService("org.apache.sling.cms.ai.audit.AiAuditService")

// Create a test audit entry
def entry = AiAuditEntry.builder()
    .userId("admin")
    .operationType(AiAuditEntry.OperationType.SUMMARIZE)
    .providerId("openai-test")
    .contentPath("/content/test/page")
    .sitePath("/content/test")
    .outcome(AiAuditEntry.Outcome.SUCCESS)
    .inputHash("abc123hash")
    .outputPreview("This is a test summary generated by AI...")
    .processingTimeMs(1234L)
    .build()

// Record the entry
def entryId = auditService.record(entry)
println "Recorded entry with ID: ${entryId}"

// Retrieve the entry
def retrieved = auditService.getEntry(entryId)
if (retrieved.isPresent()) {
    println "Successfully retrieved entry:"
    println "  User: ${retrieved.get().userId}"
    println "  Operation: ${retrieved.get().operationType}"
    println "  Provider: ${retrieved.get().providerId}"
    println "  Content: ${retrieved.get().contentPath}"
    println "  Outcome: ${retrieved.get().outcome}"
} else {
    println "ERROR: Could not retrieve entry!"
}

// Update outcome to APPLIED
auditService.updateOutcome(entryId, AiAuditEntry.Outcome.APPLIED)
println "Updated outcome to APPLIED"

// Retrieve again to verify update
def updated = auditService.getEntry(entryId)
println "New outcome: ${updated.get().outcome}"

// Query by content path
def contentEntries = auditService.getEntriesForContent("/content/test/page", 10)
println "Found ${contentEntries.size()} entries for content path"

// Query by user
def userEntries = auditService.getEntriesForUser("admin", 10)
println "Found ${userEntries.size()} entries for user 'admin'"

return "Test completed successfully!"
```

### 5. Test AI Integration

Create a servlet to test audit recording during actual AI operations:

```java
@Component(service = Servlet.class, property = {
    ServletResolverConstants.SLING_SERVLET_PATHS + "=/bin/cms/ai/test-audit",
    ServletResolverConstants.SLING_SERVLET_METHODS + "=POST"
})
public class TestAuditServlet extends SlingAllMethodsServlet {
    
    @Reference
    private AiAuditService auditService;
    
    @Override
    protected void doPost(SlingHttpServletRequest request, SlingHttpServletResponse response) 
            throws IOException {
        
        // Simulate AI operation
        long startTime = System.currentTimeMillis();
        
        String contentPath = request.getParameter("contentPath");
        String userId = request.getResourceResolver().getUserID();
        
        // Create audit entry
        AiAuditEntry entry = AiAuditEntry.builder()
            .userId(userId)
            .operationType(AiAuditEntry.OperationType.SUGGEST_TITLE)
            .providerId("openai")
            .contentPath(contentPath)
            .outcome(AiAuditEntry.Outcome.SUCCESS)
            .inputHash(hashContent(request.getParameter("content")))
            .outputPreview("Suggested title: How to Test AI Features")
            .processingTimeMs(System.currentTimeMillis() - startTime)
            .build();
        
        String entryId = auditService.record(entry);
        
        response.setContentType("application/json");
        response.getWriter().write("{\"entryId\":\"" + entryId + "\"}");
    }
}
```

### 6. Test Cleanup Function

**Via Groovy Console:**
```groovy
import org.apache.sling.cms.ai.audit.*
import java.time.Instant
import java.time.temporal.ChronoUnit

def auditService = getService("org.apache.sling.cms.ai.audit.AiAuditService")

// Create old entry (40 days ago)
def oldEntry = AiAuditEntry.builder()
    .timestamp(Instant.now().minus(40, ChronoUnit.DAYS))
    .userId("admin")
    .operationType(AiAuditEntry.OperationType.SUMMARIZE)
    .providerId("test")
    .contentPath("/content/old/page")
    .outcome(AiAuditEntry.Outcome.SUCCESS)
    .processingTimeMs(1000L)
    .build()

def oldId = auditService.record(oldEntry)
println "Created old entry: ${oldId}"

// Create recent entry
def recentEntry = AiAuditEntry.builder()
    .userId("admin")
    .operationType(AiAuditEntry.OperationType.SUMMARIZE)
    .providerId("test")
    .contentPath("/content/recent/page")
    .outcome(AiAuditEntry.Outcome.SUCCESS)
    .processingTimeMs(1000L)
    .build()

def recentId = auditService.record(recentEntry)
println "Created recent entry: ${recentId}"

// Run cleanup (30-day retention)
def deletedCount = auditService.cleanup(30)
println "Deleted ${deletedCount} entries older than 30 days"

// Verify old entry is gone
def oldRetrieved = auditService.getEntry(oldId)
println "Old entry exists: ${oldRetrieved.isPresent()}"  // Should be false

// Verify recent entry still exists
def recentRetrieved = auditService.getEntry(recentId)
println "Recent entry exists: ${recentRetrieved.isPresent()}"  // Should be true

return "Cleanup test completed!"
```

## Performance Testing

### Load Test Script

Create a Groovy script to test performance:

```groovy
import org.apache.sling.cms.ai.audit.*
import java.time.Instant

def auditService = getService("org.apache.sling.cms.ai.audit.AiAuditService")

def operationTypes = [
    AiAuditEntry.OperationType.SUMMARIZE,
    AiAuditEntry.OperationType.SUGGEST_TITLE,
    AiAuditEntry.OperationType.REWRITE,
    AiAuditEntry.OperationType.TRANSLATE
]

def providers = ["openai", "azure-openai", "anthropic", "ollama"]

def startTime = System.currentTimeMillis()
def recordedCount = 0

// Create 1000 audit entries
for (int i = 0; i < 1000; i++) {
    def entry = AiAuditEntry.builder()
        .userId("user${i % 10}")
        .operationType(operationTypes[i % operationTypes.size()])
        .providerId(providers[i % providers.size()])
        .contentPath("/content/test/page${i}")
        .outcome(AiAuditEntry.Outcome.SUCCESS)
        .processingTimeMs(500L + (i % 1000))
        .build()
    
    auditService.record(entry)
    recordedCount++
    
    if (i % 100 == 0) {
        println "Recorded ${i} entries..."
    }
}

def totalTime = System.currentTimeMillis() - startTime
println "\nPerformance Results:"
println "  Total entries: ${recordedCount}"
println "  Total time: ${totalTime}ms"
println "  Average time per entry: ${totalTime / recordedCount}ms"

// Test query performance
def queryStart = System.currentTimeMillis()
def results = auditService.getEntriesByOperationType(
    AiAuditEntry.OperationType.SUMMARIZE, 100)
def queryTime = System.currentTimeMillis() - queryStart

println "\nQuery Performance:"
println "  Results found: ${results.size()}"
println "  Query time: ${queryTime}ms"

return "Load test completed!"
```

## Monitoring & Troubleshooting

### Check Logs

```bash
tail -f crx-quickstart/logs/error.log | grep -i "audit"
```

Look for:
- ✅ "JCR-based AI Audit Service activated"
- ✅ "Recorded AI audit entry: {id}"
- ✅ "Cleaned up {n} audit entries older than {days} days"
- ❌ "Failed to get service resource resolver" (permission issues)
- ❌ "Failed to persist audit entry" (JCR write issues)

### Common Issues

#### 1. Service Not Active
**Symptom:** `auditService` is null in Groovy console

**Solution:**
- Check bundle status: `http://localhost:8082/system/console/bundles`
- Verify `org.apache.sling.cms.ai` bundle is Active
- Check for missing dependencies

#### 2. Permission Denied
**Symptom:** "Failed to get service resource resolver"

**Solution:**
- Verify service user mapping exists
- Check ACLs on `/var/audit/ai`
- Grant `jcr:all` to `sling-cms-ai` user

#### 3. Query Returns No Results
**Symptom:** Empty result list when entries should exist

**Solution:**
- Verify entries exist in CRX/DE
- Check query syntax in logs
- Ensure correct property names (case-sensitive)

### Verify Data Integrity

**Groovy Console:**
```groovy
import javax.jcr.query.Query

def resolver = resourceResolver
def queryManager = resolver.adaptTo(javax.jcr.Session.class).workspace.queryManager

def sql = """
    SELECT * FROM [nt:unstructured] AS node 
    WHERE ISDESCENDANTNODE(node, '/var/audit/ai')
    ORDER BY node.[timestamp] DESC
"""

def query = queryManager.createQuery(sql, Query.JCR_SQL2)
query.setLimit(10)

def result = query.execute()
def nodes = result.nodes

println "Recent audit entries:"
nodes.each { node ->
    println "  ${node.path}"
    println "    User: ${node.getProperty('userId')?.string}"
    println "    Operation: ${node.getProperty('operationType')?.string}"
    println "    Timestamp: ${node.getProperty('timestamp')?.date?.time}"
}

return "Verification complete!"
```
