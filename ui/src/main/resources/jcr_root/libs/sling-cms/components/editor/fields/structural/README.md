# Structural/Layout Components

This directory will contain structural and layout field components after migration.

## Planned Components

- `multifield/` - Repeating field groups with complex structure
- `repeating/` - Simple repeating fields
- `tabs/` - Tabbed sections for organizing fields
- `fieldsets/` - Collapsible fieldsets/sections
- `well/` - Card-like container for grouping fields
- `labelfield/` - Tag/label field component

## Current Status

⏳ **Not yet migrated** - Components remain at parent level for compatibility
