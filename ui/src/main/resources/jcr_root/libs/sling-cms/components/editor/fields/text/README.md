# Text Input Fields

This directory will contain text input field components after migration.

## Planned Components

- `text/` - Single-line text input
- `textarea/` - Multi-line text area
- `path/` - Path selection with search modal
- `hidden/` - Hidden input fields

## Current Status

⏳ **Not yet migrated** - Components remain at parent level for compatibility

## Migration Checklist

When migrating components to this directory:
- [ ] Copy component (don't move initially)
- [ ] Test new location
- [ ] Update documentation
- [ ] Gradual content reference updates
- [ ] 6-month deprecation period
- [ ] Remove old location
